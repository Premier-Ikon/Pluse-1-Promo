# V2 — Product catalog + order requests

## Goal

Blend a BlueCotton-style order builder with Plus One Promo’s brand, but **no payments**.
Customers browse products → complete a questionnaire → submit an **order request**.
Staff confirm accuracy/pricing in admin → customer approves → production.

## Branch

`frontend` git branch: **V2**

## New public routes

- `/shop` — catalog from admin API (fallback seed products if API down)
- `/shop/[slug]` — product detail + Order Request Builder

## Builder steps

Delivery → Color → Decoration → Design → Sizes & Qty → Contact → Submit
